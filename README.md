# 💈 Will Barber Shop

Landing page institucional para a **Will Barber Shop**, barbearia localizada no bairro Cristal, Zona Sul de Porto Alegre/RS. O objetivo do projeto é apresentar a marca, os serviços e o time de barbeiros, além de direcionar o cliente para o agendamento via app.

🔗 **Site ao vivo:** [wilgnerdev.github.io/willbarbershop](https://wilgnerdev.github.io/willbarbershop/)

---

## ✨ Funcionalidades

- Header fixo com navegação por âncoras (Galeria, Serviços, Barbeiros, Avaliações)
- Seção "Como chegar" com endereço, horário de funcionamento, telefone e Instagram
- Galeria de cortes
- Tabela de serviços e preços
- Apresentação da equipe de barbeiros
- Bloco de avaliações de clientes
- Botão de CTA "Agendar no app", integrado a um sistema externo de agendamento (AppBarber)
- Layout responsivo

## 🚀 Como executar localmente

1. Clone o repositório:
   ```
   git clone https://github.com/wilgnerdev/willbarbershop.git
   ```
2. Abra o `index.html` no navegador ou sirva a pasta com um servidor local, por exemplo:
   ```
   npx serve .
   ```
3. Acesse o endereço indicado pelo servidor (ex: `http://localhost:3000`).
